Commit conventions
- Commits are authored by aryan only — NO Codebuff co-author footer, NO
  "Generated with Codebuff" trailer in commit messages.
- Keep the existing style: concise subject line + short why/what body.
  (Also tracked in docs/commit-conventions.md)

UI style preferences
- CapCut-inspired, clean and minimal: tile/gallery layouts, dashed
  "New Project" cards, ⋯ overflow menus instead of stacked icon buttons.
- All dialogs should be in-app modals (name / confirm / notice), never
  browser prompt()/alert()/confirm(). Keyboard: Enter = confirm,
  Escape = cancel; modal focus on open.
- Projects modal supports full keyboard nav (arrows, Enter, F2, Ctrl+D,
  Delete, Esc).
- Match the text-Properties panel's clean card organization in captions.
